# Gothic II для Android

Отдельное Android-приложение, которое запускает **оригинальную Gothic II** локально, без root и без облака.
Основная цель — лицензионное **Золотое издание**: в нём можно выбрать «Ночь Ворона» или классическую
Gothic II без дополнения. Ремейк и графические моды не поддерживаются. Пользователь видит только игру:
значок → короткая загрузка → меню Gothic II → сенсорное управление, спроектированное под Gothic.
Wine, трансляция x86 → ARM64 и графические обёртки работают внутри и наружу не показываются.

Приложение распространяется **без игровых файлов**: пользователь импортирует свою легальную копию.

## Состояние

| Этап (docs/ROADMAP.md) | Статус |
|---|---|
| 1. Доказать запуск именно Gothic II Classic | Не начат: нужен телефон и легальная копия игры |
| 2. Отдельное приложение | Импорт, проверка сборки, установщик компонентов, прямой запуск, 4:3 с полями, восстановление после сбоя; **среда исполнения — заглушка** |
| 3. Сенсорный прототип | Реализован и покрыт тестами: джойстик, камера, удары, блок, меню, радиальные слоты, редактор кнопок, замер задержки |
| 4. Контекстный адаптер | Протокол, локальный сокет, рукопожатие, fallback и смена панелей готовы; сам адаптер внутри игры не написан |
| 5–6. Стабилизация и выпуск | Не начаты |

Пока среда исполнения не подключена, `GameActivity` работает с `StubRuntimeBackend`: оверлей,
арбитр ввода, сохранения и жизненный цикл можно проверять на реальном телефоне, нажатия
выводятся на экран и пишутся в журнал диагностики.

## Структура

```
core/   Чистая Kotlin/JVM-логика без Android — всё, что можно проверить тестами:
        input/    арбитр ввода, джойстик, камера, раскладка, распределение пальцев
        saves/    резервные копии, восстановление, импорт/экспорт родных сохранений
        gamedata/ проверка сборки по SHA-256, импорт игры с откатом
        config/   GOTHIC.INI, профили устройств, пользовательские настройки
        runtime/  закреплённые компоненты, описание запуска, граница со средой исполнения
        bridge/   протокол моста состояния с игровым адаптером
app/    Android-приложение: импорт через SAF, экран игры, оверлей, геймпад, настройки
docs/   Решения, архитектура, дорожная карта, план тестирования, лицензии
```

## Сборка

Нужны JDK 17+ и Android SDK (platform 35). Путь к SDK — в `local.properties` (`sdk.dir=...`).

```bash
./gradlew :core:test            # модульные тесты логики
./gradlew :app:assembleDebug    # APK (только arm64-v8a)
./gradlew :app:lintDebug        # lint, включая проверку API модуля core
```

## Как закрепить свою копию игры

Игровые файлы никуда не пересылаются. Установите debug-APK на телефон, выберите папку своей
установленной игры и нажмите «Сохранить отчёт о сборке» (или Настройки → «Отчёт о сборке игры»
после импорта). Получится текстовый файл на несколько КБ с контрольными суммами — по нему сборка
вносится в `supported_builds.ini`. Подробно: [docs/SUPPORTED_BUILDS.md](docs/SUPPORTED_BUILDS.md).
