# Журнал проекта

Хронология решений и сделанного. Актуальные следующие шаги — в `CLAUDE.md` и `docs/ROADMAP.md`.

## 2026-10-13 — сессия 1

### Исходные данные
Пользователь передал подробный план «Gothic II Classic на Android как отдельная игра» (25 разделов:
продукт, версия игры, Wine вместо Windows, архитектура на основе Winlator, 32-битное исполнение,
графика D3D7, запуск без технических экранов, сенсорное управление и бой, адаптер состояния,
сохранения, жизненный цикл, производительность, лицензии, этапы). Краткая версия решений —
`docs/PLAN.md`. Репозиторий был пустым.

### PR #1 — каркас (смёрджен)
- Gradle-проект: `core` (чистый Kotlin) и `app` (Android, minSdk 29, target 35, только arm64-v8a).
- Ввод: `InputArbiter` (приоритеты, фазы удара, блок, без очередей ударов), `KeyStateTracker`
  (удержание по источникам), `JoystickMapper` (гистерезис), `CameraMapper`, `TouchRouter`, `OverlayLayout`.
- Сохранения: `SaveManager`, `SaveBackupPolicy`. Игра: `BuildVerifier`, `GameImporter`, `GameTree`.
- Конфигурация: `IniFile`, `GothicIniWriter`, `DeviceProfile`, `UserSettings`. Среда: `LaunchSpecBuilder`,
  `RuntimeBackend`, `SessionController`. Мост: `BridgeProtocol`, `BridgeSession`, `ModeController`.
- Приложение: импорт через SAF, `GameActivity` с оверлеем, геймпад, настройки, диагностика.
- Ветка `main` создана пустым начальным коммитом (репозиторий был пуст), без переписывания истории.

### PR #2 — то, что можно без игры (смёрджен)
- `TarExtractor` + `ComponentInstaller` (безопасная распаковка, SHA-256, атомарно, идемпотентно).
- `BridgeServer` (Unix-сокет в приватном каталоге), путь и токен — через окружение запуска.
- `RadialMenu` (быстрые слоты), кнопка «последний слот», `LayoutEditor` (редактор кнопок в игре).
- `ViewportFit` (4:3 с полями), `LatencyStats`/`TimedInputSink` (задержка ввода),
  `SessionJournal` (экран восстановления после выгрузки процесса).
- Перегрев, скрытие панели при геймпаде, вибрация.
- Исправлено: соединение без рукопожатия сбрасывало ручной режим; смена режима при открытом
  радиальном меню выбирала слот.

### Решение по версии игры
Отдельная Gothic II Classic больше не продаётся (Steam/GOG — только Gold, отключить дополнение
официально нельзя; сообщество использует мод «Classic»). Пользователь нашёл раздачу на old-games.ru —
отказались: игра продаётся, а русская версия требует NoCD (обход защиты исключён планом, хэш EXE
не закрепить). У пользователя есть **купленная оригинальная Gold-копия**. Решили: цель — Gold с двумя
вариантами (Ночь Ворона и классика); для тестов пиратские копии не используются — вместо пересылки
2,6 ГБ пользователь присылает отчёт о сборке.

### PR #3 — Gold-издание и отчёт о сборке (смёрджен)
- `GameVariant` в манифесте (`[variant:<сборка>/<вариант>]`, `args=PENDING` скрывает вариант),
  `forbids=` для различения Gold и Classic.
- `BuildFingerprint` — отчёт о сборке (SHA-256 `System/` и `Data/`, черновик манифеста, список ini/mod).
- Кнопка отчёта на экране импорта и в настройках; выбор варианта; копии сохранений по вариантам.
- Пользователю отправлен debug-APK для формирования отчёта.

### Открытые вопросы
- Как именно Gold-копия пользователя запускает классическую игру (ini/мод, аргументы `-game:`,
  каталог сохранений) — ответ даст отчёт о сборке.
- Какая основа среды (форк Winlator, версия Wine WoW64, Box64) и формат архивов (`.tzst` vs `.tar.gz`).
- Совместимость обёртки D3D7→D3D9 с движком Gold 2.6 (заявлена для Gothic I и G2 NoTR — то есть для Gold).
- Почему GitHub Actions не выделяет раннер (настройки Actions/лимиты аккаунта пользователя).

## 2026-10-14

У пользователя Gold-копия из GOG в виде офлайн-установщика (`setup.exe` + 3 файла `.bin`), а не
установленной папки. Предложены способы распаковки (ПК, Termux + innoextract `--gog`, Winlator) —
записаны в docs/SUPPORTED_BUILDS.md. Встроенная распаковка установщика GOG добавлена в ROADMAP
как доработка после этапа 1. Сборка, судя по источнику, — GOG-версия (язык уточнится по отчёту;
возможно, понадобится отдельная секция `[build:g2-gold-gog-…]`).
