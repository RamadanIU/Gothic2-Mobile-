# Принятые решения

Краткая версия исходного плана. Нумерация разделов совпадает с исходным планом, на неё
ссылаются комментарии в коде («раздел N плана»).

1. **Продукт.** Одно приложение, только Gothic II Classic, локально, без root, офлайн после установки.
   Пользователь не видит рабочего стола Windows, Wine Configuration, контейнеров, выбора EXE, терминала,
   DLL, менеджера модов и выбора рендерера. В настройках — только игровые параметры.
2. **Версия игры.** *Решение изменено:* отдельная Classic больше не продаётся, лицензионные копии —
   Gold-издание (Steam, GOG, диски). Основная цель — Gold с двумя вариантами запуска: «Ночь Ворона»
   и классическая Gothic II без дополнения; игрок выбирает вариант, сохранения у вариантов раздельные.
   Отдельная Classic с диска поддерживается как дополнительная сборка. Каждая сборка опознаётся по
   SHA-256 EXE и закрепляется по отчёту о сборке с телефона игрока. Исправления — только технические.
3. **«Windows».** Не полная ОС, а Wine. Профиль Windows 7 — основной кандидат, XP — для сравнения.
4. **Архитектура.** Основа класса Winlator без универсального интерфейса; модули GameActivity,
   RuntimeManager, DeviceProfile, InputRouter, TouchOverlay, GameStateBridge, SaveManager, Diagnostics.
5. **32 бита.** Основной кандидат — ARM64 + Box64 + Wine WoW64; запасной — Box86 + x86 Wine.
   Версии закрепляются, автообновление запрещено.
6. **Графика.** Игра использует Direct3D 7. Сравниваются две цепочки: WineD3D (эталон корректности)
   и D3D7→D3D9→DXVK→Vulkan. Совместимость обёртки с Classic не подтверждена — проверяется.
   Первая платформа — Snapdragon/Adreno. Нельзя ускорять ценой исчезновения ночи, тумана, объектов.
7. **Запуск.** Первый раз — импорт папки установленной игры, проверка, копирование. Далее — сразу
   меню Gothic. Разрешение задаётся через GOTHIC.INI. Автозагрузка последнего сохранения —
   только через адаптер, не макросом.
8. **Управление.** Мало кнопок, режимы игрок не переключает. Слева джойстик (в меню — стрелки);
   справа обзор пальцем и одна главная кнопка (действие/удар/выстрел/магия, в меню — «Выбрать»;
   свайпы — боковые удары и блок), прыжок, оружие с колесом слотов, в бою — блок; сверху — сумка,
   «Ещё» и одна кнопка Esc («Меню»/«Назад»). Редкое — в «Ещё». Зона касания ≥ 48 dp,
   раскладка для левши, размер/положение/прозрачность настраиваются (2026-10-15).
9. **Движение и камера.** Скорости дискретны (ходьба/бег) с гистерезисом. Камера — относительная
   мышь без сглаживания. Палец принадлежит элементу, на котором начал касание.
10. **Ближний бой.** Удар = действие + направление с фазами и удержанием; блок — пока удерживается.
    Единый арбитр с приоритетами: меню/диалог → блок/удар → цель → движение → камера.
    Без авто-комбо, без очередей ударов, без постоянного боевого модификатора.
11. **Цель, стрельба, магия.** Штатная фиксация цели; камера не срывает её. Иконки рун и мана —
    только через адаптер.
12. **Контекст.** Уровень 1 — догадка по клавишам, которые отправляет приложение (Tab, Esc, Space,
    слоты), и по намерению игрока (камера на экране меню), запасной пункт в «Ещё» (2026-10-15). Уровень 2 — адаптер внутри процесса
    игры: версия по SHA-256 EXE, локальный IPC с токеном, без сетевого порта, белый список команд.
    Без адаптера — универсальная панель, а не ошибочные контекстные кнопки. Без OCR.
13. **Диалоги, инвентарь, торговля** — отдельные панели навигации; опасные действия защищены.
14. **Надёжность ввода.** Учёт удержания по источникам; releaseAll при потере фокуса и ACTION_CANCEL;
    нет очереди старых движений камеры; измеряется задержка «касание → реакция».
15. **Изображение.** Стартовые профили 800×600 / 960×540 / 1280×720 при 30 FPS — кандидаты,
    не обещание. Без корректной широкоформатной проекции — 4:3 с полями.
16. **Сохранения.** Родные сохранения Gothic; копия — только после подтверждённого завершения записи;
    несколько поколений; импорт/экспорт; без слепого автосохранения.
17. **Жизненный цикл.** Потеря фокуса: снять ввод → пауза → аудиофокус → состояние. Esc — не пауза.
18. **Android.** Без root, 16 КБ страницы, SELinux, правила исполнения нативного кода — проверяются
    на этапе 1. Папка игры выбирается через SAF; игра запускается прямо из неё по разрешению «Файлы»
    (targetSdk 28, как у Winlator; решение пользователя, 2026-10-15), копия в приложение — запасной путь.
19. **Устройства.** Тестовая база: Snapdragon 865/870 и 8 Gen 2, 8 ГБ RAM. Цель — стабильные 30 FPS,
    час без вылета, тесты 30–60 минут после прогрева.
20. **Звук и ролики** сохраняются полностью; пропускаются только логотипы.
21. **Геймпад** — через тот же арбитр.
22. **Лицензии.** Без игровых ресурсов в APK; учёт лицензий всех компонентов (Winlator — LGPL-2.1).
23. **Этапы** — docs/ROADMAP.md. 24. **Команда** — Android, системная совместимость, C++/Gothic, QA.
25. **Готовность** — критерии в docs/ROADMAP.md («Условия готовности»).
